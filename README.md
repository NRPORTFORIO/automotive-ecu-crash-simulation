# 自動車用ECU衝突安全制御シミュレータ ＆ 実験データ自動解析ツール

本プロジェクトは、自動車の**衝突安全性能開発（評価・解析・データ分析）**業務への適性を証明するために構築した、完全自主開発のポートフォリオです。

手元にPC環境がないという制約下において、スマートフォンのテキストエディタとオンラインコンパイラ（Wandbox）を活用し、頭の中でメモリ配置やポインタの挙動を完全にシミュレートしながら、設計・開発・デバッグまでを一人で行いました。

安全最優先の設計思想に基づく「C言語によるECU制御」と、客観的な合否判定を行う「Pythonによるテストデータ解析」の2つのシステムで構成されています。

---

## 🛠️ プロジェクト構成

本リポジトリは、実際の衝突安全開発における**「制御（テスト対象）」**と**「評価（データ解析）」**のサイクルを再現した2つのファイルで構成されています。

### 1. 【C言語】車載ECU衝突制御プログラム (`ecu_crash_control.c`)
衝突時のミリ秒単位の挙動を想定し、高額な装置や乗員の安全を守るためのロジックを実装しています。
* **誤作動防止（デバウンス処理）**：悪路走行時の衝撃（一瞬のノイズ）でのエアバッグ誤作動を防ぐため、しきい値（4.5G）を連続検知するフィルター回路を実装。
* **入力値のバリデーション**：センサー故障時の異常値（-99.0G）を即座に検知。
* **フェイルセーフ**：衝突検知時、およびセンサー故障時の二次災害（車両火災など）を防ぐため、ミリ秒単位で「エアバッグ展開フラグ」と「燃料ポンプ緊急停止フラグ」をトリガーする安全設計。

### 2. 【Python】衝突実験ログ自動評価スクリプト (`analyze_crash_log.py`)
ECUから吐き出されたタイムスタンプ付きの実験ログ（CSVデータ）を `pandas` を用いて読み込み、客観的な性能評価を自動化するスクリプトです。
* **センサー健全性の自動チェック**：ログ内の異常値を検知し、フェイルセーフが正しく機能したかをログから追跡。
* **ミリ秒単位の応答速度解析**：本衝突開始からエアバッグ展開までの時間をミリ秒単位で計算。法規・社内基準（30ms以内）をクリアしているかを算出し、**`【PASS】` / `【FAIL】` を自動判定**。
* **統計データの抽出**：実験中の最大衝撃値（Max-G）を自動抽出し、車体構造の強度評価に繋がるデータを提示。

## 💡 本プロジェクトにおける自身の強みと資質

1. **環境の制約に負けない自学自習力と執念**
   PC環境がない状態でも、「今あるリソース（スマートフォン）で何ができるか」を客観的に考え、論理的なコードとして成果物を形にする行動力があります。
2. **安全第一の設計・評価思想**
   「バグや異常値は必ず発生する」という前提に立ち、システムを安全に維持・停止させるフェイルセーフの論理的思考力を、エアコン制御等の過去作に続き本作品でも徹底しています。
3. **客観的なデータ分析力とコスト意識**
   ただデータをグラフ化するのではなく、法規や社内基準を満たしているかを自動判定する「評価業務の本質」を意識した構築を行いました。また、簿記の勉強で培った財務・原価意識をベースに、エラー（不具合）による損失を未然に防ぎ、効率的な「仕組み・流れ」を創ることで企業の利益に貢献します。
